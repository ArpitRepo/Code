ITestListener is an interface provided by TestNG that allows you to create custom listeners to perform specific
actions at various points during the test execution lifecycle
In TestNG, you can get the test result value using the ITestResult interface. This interface provides methods to
retrieve details about the test execution, such as the test method name, status, start time, end time, and any
exceptions that were thrown.

import org.testng.ITestContext;
import org.testng.ITestListener;
import org.testng.ITestResult;
import com.aventstack.extentreports.ExtentReports;
import com.aventstack.extentreports.ExtentTest;
import com.aventstack.extentreports.Status;
import com.aventstack.extentreports.reporter.ExtentSparkReporter;

public class CustomTestListener implements ITestListener {
    private static ExtentReports extent;
    private static ExtentTest test;

    @Override
    public void onStart(ITestContext context) {
        ExtentSparkReporter reporter = new ExtentSparkReporter("test-output/ExtentReport.html");
        extent = new ExtentReports();
        extent.attachReporter(reporter);
    }

    @Override
    public void onFinish(ITestContext context) {
        extent.flush();
    }

    @Override
    public void onTestStart(ITestResult result) {
        test = extent.createTest(result.getMethod().getMethodName());
    }

    @Override
    public void onTestSuccess(ITestResult result) {
        test.log(Status.PASS, "Test Passed: " + result.getMethod().getMethodName());  //Test Passed: loginTest

    }

    @Override
    public void onTestFailure(ITestResult result) {
        test.log(Status.FAIL, "Test Failed: " + result.getMethod().getMethodName());
        test.log(Status.FAIL, result.getThrowable());
    }

    @Override
    public void onTestSkipped(ITestResult result) {
        test.log(Status.SKIP, "Test Skipped: " + result.getMethod().getMethodName());
    }

    @Override
    public void onTestFailedButWithinSuccessPercentage(ITestResult result) {
        test.log(Status.WARNING, "Test Failed but within success percentage: " + result.getMethod().getMethodName());
    }
}

import io.cucumber.java.After;
import io.cucumber.java.Scenario;
import org.testng.ITestResult;
import org.testng.Reporter;

public class Hooks {

    @After
    public void afterScenario(Scenario scenario) {
        ITestResult testResult = Reporter.getCurrentTestResult();

        System.out.println("Scenario Name: " + scenario.getName());
        if (testResult.getStatus() == ITestResult.SUCCESS) {
            System.out.println("Scenario Passed");
        } else if (testResult.getStatus() == ITestResult.FAILURE) {
            System.out.println("Scenario Failed");
            System.out.println("Error: " + testResult.getThrowable());
        } else if (testResult.getStatus() == ITestResult.SKIP) {
            System.out.println("Scenario Skipped");
        }
    }
}


In TestNG, Reporter.getCurrentTestResult() is used to obtain the current test result context during the execution of a test method. This allows you
to access detailed information about the current test case, such as its status, parameters, start time, end time, and any associated exceptions.

ITestResult is an interface in TestNG that represents the result of a test method. It provides methods to access various details about the test
execution, such as its status, start and end times, parameters, and any exceptions thrown during the test.
Reporter is a utility class in TestNG that provides methods for logging and reporting purposes during test execution. It allows you to log messages
that can be included in the test reports, retrieve the current test result, and interact with the reporting system in TestNG.

In TestNG, when you use the @AfterMethod annotation with a method that accepts an ITestResult parameter, TestNG automatically injects an instance
of ITestResult representing the result of the test method that just finished executing. You do not need to manually create an
ßinstance of ITestResult.
