No, the query SELECT value, COUNT(*) AS count FROM numbers WHERE count(*) > 1; will not work because
WHERE cannot be used with aggregate functions like COUNT(*) directly in that way. Instead, you should use
the HAVING clause to filter results after grouping.

SELECT value, COUNT(*) AS count
FROM numbers
GROUP BY value
HAVING COUNT(*) > 1;

DELETE:

Use when you need to remove specific rows.
Supports WHERE clause for conditional deletions.
Slower for large data sets due to logging.
Can be rolled back if within a transaction.

TRUNCATE:
Use when you need to quickly remove all rows from a table.
Faster than DELETE for large tables as it doesn't log individual row deletions.
May not be reversible depending on the database system.
Doesn't fire triggers.

DROP:
Use when you need to completely remove a table (or database).
Fastest as it removes the entire structure and data.
Irreversible in many systems.
All associated objects like indexes, constraints, and triggers are also removed.
DROP removes an entire database object (like a table) from the database schema, including all data and
associated metadata, and it also cannot be rolled back.

DELETE FROM employees WHERE department_id = 5;
TRUNCATE TABLE employees;
DROP TABLE employees;

Group By rules
Columns in the SELECT clause: Any columns that are not part of an aggregate function (such as SUM, AVG, COUNT, MAX, MIN)
must be included in the GROUP BY clause.
SELECT department, SUM(salary)
FROM employees
GROUP BY department;

Columns in the ORDER BY clause must be part of the GROUP BY clause, used in aggregate functions, or be constant values.

The HAVING clause allows you to apply conditions to groups of rows generated by the GROUP BY clause. It filters out groups that do not meet the specified conditions.
Conditions specified in the HAVING clause often involve aggregate functions (e.g., SUM, AVG, COUNT, MAX, MIN) because they operate on groups of rows.
SELECT product_id, SUM(sales_amount) AS total_sales
FROM sales
WHERE region IN ('North', 'South', 'East', 'West')  -- Filter for specific regions
GROUP BY product_id
HAVING SUM(sales_amount) > 1000;  -- Filter groups with total sales > 1000

Difference from WHERE Clause:

The WHERE clause filters individual rows before any grouping occurs.
The HAVING clause filters groups after the grouping has taken place.
