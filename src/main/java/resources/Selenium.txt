@Before: This annotation is used to specify a method that should be executed before each scenario. It is typically used for setup tasks such as initializing test data or setting up the environment.

@After: This annotation is used to specify a method that should be executed after each scenario. It is commonly used for teardown tasks such as closing resources or cleaning up test data.

@BeforeStep: This annotation is used to specify a method that should be executed before each step within a scenario. It can be useful for tasks that need to be performed before each step, such as logging or capturing screenshots.

@AfterStep: This annotation is used to specify a method that should be executed after each step within a scenario. It can be useful for tasks that need to be performed after each step, such as verifying the state of the application.

@BeforeAll: This annotation is used to specify a method that should be executed before all scenarios in a feature file. It is typically used for setup tasks that need to be performed once before running any scenarios in a feature.

@AfterAll: This annotation is used to specify a method that should be executed after all scenarios in a feature file. It is commonly used for teardown tasks that need to be performed once after running all scenarios in a feature.

This exception is a more general term that can apply to any Java object reference becoming invalid or outdated.
In the context of Selenium or web automation, a stale reference exception might occur when an object reference other than a DOM element becomes stale, such as a

This can happen due to various reasons, including:
The object being garbage-collected or modified by another thread.

import org.openqa.selenium.chrome.ChromeDriver;

public class WebDriverSingleton {
    private static WebDriver driver;

    private WebDriverSingleton() {
        // Private constructor to prevent instantiation
    }

    public static WebDriver getDriver() {
        if (driver == null) {
            // Set up WebDriver (in this example, ChromeDriver)
            System.setProperty("webdriver.chrome.driver", "path/to/chromedriver");
            ChromeOptions options = new ChromeOptions();
            // Set any desired options
            // For example, options.addArguments("--headless"); // Run Chrome in headless mode
            driver = new ChromeDriver(options);
        }
        return driver;
    }

    public static void quitDriver() {
        if (driver != null) {
            driver.quit();
            driver = null;
        }
    }
}

In the setUp() method annotated with @BeforeScenario, the WebDriver instance is obtained from the WebDriverManager
